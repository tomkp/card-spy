Card Spy

A smartcard and NFC IDE

Card Spy works with smartcards and NFC tags through any PC/SC reader. Send APDUs, explore cards, write scripts in TypeScript, and record a card to replay without it.

Card explorer

Explore a card

Explore reads the ATR, the payment applications with their records, counters and transaction log, and the memory and NDEF messages of NFC tags. It also checks for common applications such as PIV, OpenPGP and FIDO.

Values are shown with their names and decoded where the format is known: dates, amounts, currencies, country codes, CVM lists and ISO 7816-4 file control parameters.

APDU console

Send APDUs and read the responses

Type a command in hex, or a shortcut such as select 1PAY.SYS.DDF01. The trace lists the exchanges from the console, the explorer and scripts, with the command name, status word and timing. Select one to see the header fields, what the status word means and the response as a TLV tree. Hovering over a tag highlights its bytes in the hex dump.

On T=0 cards, Card Spy sends GET RESPONSE after 61xx and retries with the right length after 6Cxx. Both show up in the trace.

Scripts

Scripts in TypeScript

Scripts use a small card API, with type checking and completion in the editor. Run one against any reader, or step through it with F10: Card Spy stops before each APDU and highlights the line that sends it. 

const fci = (await card.select('A0000000031010')).expectOk();
log(fci.tlv());

Virtual cards

Save a session with a real card as a virtual card and replay it without the card. Virtual cards are JSON files you can edit and keep in version control. Two demo cards are included.

Readers

Works with contact and contactless PC/SC readers, such as the ACR122U. NFC tags like NTAG and MIFARE Ultralight are read with the reader's storage card commands.

Decoding

EMV and ISO 7816 tag dictionaries, NDEF, a list of known AIDs and status word meanings, including Java Card's. When a card rejects a command, Card Spy suggests the likely reason.
